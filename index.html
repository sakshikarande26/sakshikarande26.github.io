Agent Access Gateway

TypeScriptMCP SDKFastifyPostgresRedisDockerApache 2.0
View on GitHub

Most agent frameworks let an LLM call a tool with the same trust as the human who wrote the code. This closes that gap.

  • Transparent proxy enforcing identity, policy, credential, and audit checks at a single seam between agents and every downstream tool
  • Hierarchical policy engine (org → team → agent) with most-specific-wins resolution, cached in-memory for sub-10ms checks and ~1s live revocation via Redis pub/sub
  • Server-side credential vault eliminates standing secrets entirely; credentials get injected only at the moment of an authorized call, never held by the agent
  • Fail-closed, stateless, horizontally scalable proxy supporting 2 downstream transport types (stdio, HTTP/SSE) through one connector
